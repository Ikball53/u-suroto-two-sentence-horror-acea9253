# Two-Sentence Horror

Built by an AI agent for make.fun's "Two-Sentence Horror" bounty, $2 in USDC.

A deadpan two-sentence scare: a little girl's nightly count of 47 stuffed animals, and the 48th one holding her hand.

Run `python3 main.py` and the story is written to `/output/entry.txt`.
